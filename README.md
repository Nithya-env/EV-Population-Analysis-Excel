# Electric Vehicle Population Analysis

## Project Overview
This project focuses on analyzing Electric Vehicle (EV) population data using Microsoft Excel. It provides insights into electric vehicle adoption, manufacturer distribution, vehicle types, model years, and geographical trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Dashboard

## Dataset Information
The dataset contains 150,482 records and 17 columns, including:
- County and City
- Model Year
- Vehicle Make and Model
- Electric Vehicle Type
- Electric Range
- Base MSRP
- Vehicle Location

## Key Analysis Areas
- Total Electric Vehicles
- BEV vs PHEV Distribution
- EV Adoption by Model Year
- Top Vehicle Manufacturers
- Geographical Distribution
- Electric Range Analysis

## Project Objective
To transform raw electric vehicle data into meaningful insights through an interactive Excel dashboard.

## Dataset Source

The dataset used in this project was obtained from Kaggle.

**Source:** [Electric Vehicle Population Dataset](https://www.kaggle.com/datasets/yashusinghal/electric-vehicle-population-dataset)

The dataset contains information about electric vehicle population, manufacturers, models, model years, electric ranges, and geographical locations.
